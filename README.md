# הגשה סופית - הטיה גזעית אינטרסקציונלית במד-חמצן ובמודלים של למידת מכונה

פרויקט גמר בקורס למידת מכונה ברפואה. הפרויקט בודק את ההטיה הגזעית הידועה של מד-החמצן (Pulse Oximeter),
את ההצטלבות שלה עם מין, ואת ההתפשטות שלה למודל של למידת מכונה, ומציע דרך לרסן אותה. כל הנתונים מבוססים על MIMIC-IV v3.1.

תומר נתן.

## מבנה התיקייה

```
הגשה סופית/
  Pulse Oximetry Fairness - Research Paper.docx   ← המאמר המלא (כולל פרק הדיון)

  code/                                            ← קוד הצינור המלא + הדאטה המעובד + המחברת
  figures/                                          ← כל הגרפים שבמאמר
```

## איך מריצים

הדאטה המעובד כבר כלול בתיקייה code, כך שאפשר לשחזר את התוצאות המרכזיות בלי להוריד את MIMIC מחדש.
מריצים מתוך התיקייה code, למשל:

```
cd code
python3 baseline.py          # מודל הבסיס וההטיה שהוא יורש
python3 error_analysis.py     # ניתוח הטעויות + הגרף
python3 occult_def.py         # הטיית המכשיר, כולל אינטרסקציונלי
python3 proposed_model.py     # המודל המוצע (דורש PyTorch)
```

השלבים שדורשים את MIMIC הגולמי (חילוץ, עיבוד מקדים, העשרת פיצ'רים) לא רצים בלי גישה למאגר, וזה מצוין בטבלה למעלה.

## דאטה וסביבה

מאגר MIMIC-IV הוא מאגר עם הרשאות תחת הסכם שימוש, ולכן הנתונים הגולמיים של המטופלים אינם מצורפים כאן.
מה שכן מצורף הוא קובצי הזוגות המעובדים (SpO2 מול SaO2 עם דמוגרפיה), שהם נגזרת מצומצמת שמספיקה כדי לשחזר את הניתוח והמודלים.
הרצת הצינור המלא מאפס דורשת גישה מאושרת ל-MIMIC-IV v3.1.

חבילות נדרשות: pandas, numpy, scikit-learn, matplotlib, pyarrow, ובנוסף torch עבור proposed_model.py.
כל הריצות נעשו על מחשב נייד רגיל (Apple M1 Pro, 32 GB, בלי GPU), והאימון אורך שניות בודדות.
